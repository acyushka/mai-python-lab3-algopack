# Алгоритмический пакет

## Введение

Реализованы все требования на максимум: математические функции, сортировки, и стек на list.
В main.py точка запуска, используется Typer, не знаю можно ли это назвать cli

## Архитектура проекта

```shell
project/
├── src/
│   ├── dependencies/ # Инъекция зависимостей
│   │   └── container.py         # мини DI Container
│   ├── services/     # ГЛАВНАЯ БИЗНЕС-ЛОГИКА
│   │   ├── math_service.py # класс сервиса со Фибоначчи и факториалом
│   │   ├── sort_service.py # класс сервиса со всеми сортировками
│   │   └── structures.py # класс стека на list c min за O(1)
│   └── main.py       # Точка входа, Typer, мини cli
├── tests/
│   ├── conftest.py              # Фикстуры для тестов
│   ├── test_math.py
│   ├── test_sort.py  
│   └── test_stack.py
├── .gitignore
├── .pre-commit-config.yaml      # Линтеры и тп
├── pyproject.toml               # Настройки и описание проекта
├── requirements.txt             # Зависимости
└── README.md                    # Документация
```

## Запуск пакета

1) Форкаем репозиторий:

```shell
git clone <ссылка на репозиторий>
```

3) Создаем и активируем дефолтное виртуальное окружение и импортируем зависимости из requirements.txt

4) Прописываем команду запуска программы + требуемую функцию:
 - если сортировки, Фибоначчи, факториал - указываем их после src.main вместе с входными данными и возможными флагами
 - (если вводим список то можно вот так: "1 2 3 4 5" - т.е. без скобок)
 - если нужен стек - после src.main пишем просто stack, потом будет вход в оболочку структуры и там можно вводить уже просто команды стека с данными
 - (для выхода из стека пишем exit или quit)

```shell
python -m src.main <команда> <данные> <опция> <данные для опции> 
```
